# Binary Search Mini Projects

Three beginner-friendly Java mini-projects demonstrating the practical use of Binary Search.

## Projects

### 1. Number Guessing Game
The computer tries to guess a number between 1 and 100 using Binary Search.

**Concepts:** Binary Search, loops, user input, conditions

### 2. Search Race
Compares Linear Search and Binary Search by counting the number of steps required to find a target.

**Concepts:** Linear Search, Binary Search, Time Complexity

### 3. Treasure Hunt
Uses Binary Search to find a hidden treasure between 1 and 100.

**Concepts:** Binary Search, loops, conditions, search space reduction

## Technologies Used

- Java
- Data Structures and Algorithms
- Binary Search

## Time Complexity

| Algorithm | Time Complexity |
|-----------|-----------------|
| Linear Search | O(n) |
| Binary Search | O(log n) |
