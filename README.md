# DAA Mini Projects

A collection of simple Java mini-projects created to understand and demonstrate important **Data Structures and Algorithms (DAA)** concepts.

## Projects

### 1. Number Guessing Game
A number guessing game where the computer uses **Binary Search** to find the number chosen by the user.

**Concept:** Binary Search

### 2. Search Race
Compares **Linear Search** and **Binary Search** by counting the number of steps required to find a target.

**Concepts:** Linear Search, Binary Search, Time Complexity

### 3. Treasure Hunt
A simple treasure-hunting game that uses **Binary Search** to find a hidden treasure between 1 and 100.

**Concept:** Binary Search

### 4. Sorting Race
Compares **Bubble Sort** and **Selection Sort** by counting the number of comparisons performed by each algorithm.

**Concepts:** Bubble Sort, Selection Sort, Sorting

### 5. Activity Scheduler
Selects the maximum number of non-overlapping activities using the **Greedy Algorithm**.

**Concept:** Activity Selection, Greedy Algorithm

### 6. Prim's Algorithm
Finds the **Minimum Spanning Tree (MST)** of a weighted graph using Prim's greedy approach.

**Concepts:** Greedy Algorithm, Minimum Spanning Tree, Graph

### 7. Kruskal's Algorithm
Finds the **Minimum Spanning Tree (MST)** by selecting the smallest edges while avoiding cycles.

**Concepts:** Greedy Algorithm, Minimum Spanning Tree, Graph

### 8. Dijkstra's Algorithm
Finds the **shortest distance from a starting vertex to all other vertices** in a weighted graph.

**Concepts:** Greedy Algorithm, Shortest Path, Graph

## Time Complexity

| Algorithm | Time Complexity |
|---|---|
| Linear Search | O(n) |
| Binary Search | O(log n) |
| Bubble Sort | O(n²) |
| Selection Sort | O(n²) |
| Activity Selection | O(n) |
| Prim's Algorithm | O(V²) |
| Kruskal's Algorithm | O(E log E) |
| Dijkstra's Algorithm | O(V²) |

> The Prim's and Dijkstra's implementations in this repository use a simple adjacency-matrix approach, giving O(V²) time complexity.
